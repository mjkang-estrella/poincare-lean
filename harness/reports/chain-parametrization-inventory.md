## Minimal proposed interfaces

This section specifies new work, not declarations claimed to exist. Keep the original theorem statements and generic route intact; implement the generalized route in new modules and make the generic construction an instance.

1. **A supplied normal chart and its frame.** Reuse `CartanSourceExponential.Family` for intrinsic `normal : M → OpenPartialHomeomorph M E` and its two anchor laws. For a chart-local construction retain a patch index and its anchor set, rather than postulating global `Family.JointlyRegular`. Bundle a frame equivalence from the fixed chart's velocity coordinates to the anchor coordinates consumed by `TangentAlignment`. At first the map kernel may take any `K : E ≃L[ℝ] E`; the geometric adapter then sets `K = L ∘ J`, with the needed metric identity. The source family's metric parameter alone supplies none of these properties. This follows directly from the three fields of `Family` and the definition of `TangentAlignment` cited above.
2. **The supplied germ interpretation.** Define `germ S F x p K` by `S.normal x`, then `K`, then `F.chart p`, then `(chartAt E p).symm`. Parameterize `ChainState.germ`/`map` by this interpretation. The bare `anchor/target/alignment` state can remain unchanged when `J` is part of the interpretation. If an implementation instead stores a patch index in each state, state equality in `Data.successor_eq` cannot ignore that field; it must compare geometric states or germs. This constraint is visible in [DifferentialInducedSuccessor.lean, `Data.successor_eq`](../../Poincare/Global/DifferentialInducedSuccessor.lean#L649) and its `chainState_policy_independent` proof.
3. **A geometric successor datum.** Prefer a new structure recording membership of the new point in the supplied germ source and that the actual derivative, expressed in the new anchor/target coordinates, is an invertible metric-preserving map. Derive its alignment from that derivative. Keep `v,A,B` and the chart-exponential fields in a separate sufficient constructor, modeled on `CartanTargetExponential.Data`, rather than requiring `source_mem_oldChart` for a preferred chart the germ no longer uses. Port `Data.alignment_clm_eq_of_reanchoredChartMap_eventuallyEq`, `Data.successor_eq_of_eqOn_open`, and witness independence to the actual map. The existing [CartanTargetExponentialFamily.lean, `inducedTangentAlignmentOfCoordinatePullback`](../../Poincare/Global/CartanTargetExponentialFamily.lean#L799) is a checked coordinate-only bridge, though its old-chart assumptions still need to be supplied or replaced by explicit fixed-chart transitions.
4. **Local quantitative geometric contracts, separately from the normal-chart structure.** State source coverage, successor-data production, and successor equality on common sources in a fixed patch and a fixed target patch. Supply positive radii before choosing the moving anchors. For equality, also prove a smaller common metric ball lies in both sources if a full-ball grid consumer is to be retained. Use finite chart patches/compact subregions to obtain simultaneous bounds. Do not require continuity of a discontinuously selected global chart normal or a global lower bound for an arbitrary `Classical.choose` radius. The existing local-cover proofs can be ported with the new data type because they use open controlled loci, diagonal membership, and inclusions. Their current conclusion is demonstrably still old H1.
5. **A germ-only atlas gluing structure.** Replace `target/alignment` in the topological gluing kernel by `germ : M → OpenPartialHomeomorph M RoundSphere3` and retain the five domain/compatibility fields. The geometric route supplies this structure; the old `RestrictedCompatibleCartanAtlasData3` becomes an adapter. The proof at `isLocalHomeomorph_diagonalDevelopment` only restricts an open partial homeomorphism and uses `EqOn`, so its topological conclusion can be shared.

The fixed-chart analytic input has two details that the adapter must preserve. [FixedChartUniformNormalRadius.lean, `expChart`, `F`, `endpointDerivative`](../../Poincare/Global/FixedChartUniformNormalRadius.lean#L21) uses endpoint time `T`, with derivative `(u,w) ↦ (u,u + T • w)`. Normalize velocity by `T⁻¹` to compare with the time-one `expAt` convention. Its final theorem takes `Γ := GeodesicTransport.chartChristoffelField g x₀`, the **fixed anchor's blended field**. To use it as the manifold geodesic field, choose the requested position neighborhood `U` inside the fixed cutoff-one/chart zone. The theorem preserves positions in `U`; it does not itself assert that every position lies in that zone. See [GeodesicFlowJointDerivative.lean, `exists_uniform_local_geodesic_chart_flow_initialState_C1`](../../Poincare/Global/GeodesicFlowJointDerivative.lean#L513), [FixedChartUniformNormalRadius.lean, `exists_uniform_local_geodesic_chart_flow_normal_neighborhoods`](../../Poincare/Global/FixedChartUniformNormalRadius.lean#L315), and [IsometryInstantiate.lean, `cutoffOneLocus_mem_nhds_anchor`](../../Poincare/Global/IsometryInstantiate.lean).

The compact theorem's exact conclusion is `InjOn (expChart α T z) (ball 0 ρ)` and `ball z ρ ⊆ expChart α T z '' ball 0 R`, for a prescribed positive `R`. It does **not** say the coverage ball is the image of `ball 0 ρ`, and it does not give a single globally chosen source `Family`. Retain `R` and `ρ` separately in the adapter. Its local product partial homeomorphism is the usable inverse-family construction.

The controlled atlas reduction remains useful independently. [ControlledChartInstance.lean, `exists_controlled_chartedSpace_source_persistence`](../../Poincare/Global/ControlledChartInstance.lean#L191) gives uniform preferred-chart source balls; [ConnectionInstanceNaturality.lean, `exists_controlled_recognition_reduction'`](../../Poincare/Global/ConnectionInstanceNaturality.lean#L465) reduces recognition to that instance.
