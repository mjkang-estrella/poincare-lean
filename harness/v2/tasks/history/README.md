# Initial local task snapshots

These files preserve the task text supplied to the local implementation workers.
Directory scopes ending in a slash were rejected during integration validation.
The current records one directory above replace those spellings with explicit
recursive globs in new revisions. The source changes were independently checked
against the same recorded base and file ownership.

These snapshots are historical evidence, not runnable Tasks. They were not
registered or dispatched in the persistent Harness database. Preserve their
bytes; use the corrected current records for schema validation.
